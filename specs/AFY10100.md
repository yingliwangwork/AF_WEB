## 使用者案例
### UC-001 - 載入公會通報查詢頁
**使用者案例描述**: 使用者進入頁面時取得查詢條件、彙整資料、通報明細、操作權限及代碼對照資料。

**前置條件**: 使用者可存取 AFY10100。

**主流程**:
1. 元件掛載。
2. 系統呼叫提示資料 API。
3. 系統顯示查詢條件、保障與保費彙整、新制通報資料明細。
4. 系統依回應決定是否顯示同步更新選項及即時取回按鈕。

**替代流程**: API 回傳失敗時，由共用 HTTP Client 顯示錯誤狀態。

**事後條件**: 頁面顯示本次伺服器回傳資料。

### UC-002 - 查詢公會通報資料
**使用者案例描述**: 使用者以身份證字號或統一編號、契約角色及保單效力查詢資料。

**前置條件**: 頁面已載入。

**主流程**:
1. 使用者輸入查詢條件。
2. 使用者按下 F2 查詢按鈕或 F2 快速鍵。
3. 系統送出查詢請求。
4. 系統以回應資料刷新彙整與明細內容。

**替代流程**: API 回傳失敗時，由共用 HTTP Client 顯示錯誤狀態。

**事後條件**: 頁面顯示符合條件的資料。

### UC-003 - 選取並編輯通報資料
**使用者案例描述**: 使用者從明細表選取一筆資料，檢視及修改可編輯欄位。

**前置條件**: 查詢結果至少有一筆資料。

**主流程**:
1. 使用者單選一筆通報資料。
2. 系統顯示資料編輯區並回填該筆資料。
3. 使用者調整保障金額、保經代分類、要保人資料、性別或公自費件。
4. 使用者按下 F9 修改按鈕或 F9 快速鍵。
5. 系統送出修改請求並刷新頁面資料。

**替代流程**:
- 使用者按下取消時，系統清除選取並隱藏資料編輯區。
- API 回傳失敗時，由共用 HTTP Client 顯示錯誤狀態。

**事後條件**: 修改成功後顯示伺服器回傳的最新資料。

### UC-004 - 刪除通報資料
**使用者案例描述**: 使用者刪除目前選取的通報資料。

**前置條件**: 已選取一筆通報資料。

**主流程**:
1. 使用者按下 F10 刪除按鈕或 F10 快速鍵。
2. 系統送出刪除請求。
3. 系統刷新頁面資料。

**替代流程**: API 回傳失敗時，由共用 HTTP Client 顯示錯誤狀態。

**事後條件**: 刪除成功後不再顯示已刪除資料。

### UC-005 - 即時取回公會資料
**使用者案例描述**: 有操作權限的使用者以身份證字號或統一編號即時取回公會資料。

**前置條件**: 回應資料允許即時取回操作。

**主流程**:
1. 使用者輸入身份證字號或統一編號。
2. 使用者按下 F8 即時取回公會資料按鈕或 F8 快速鍵。
3. 系統檢核輸入不得為空值。
4. 系統呼叫證號檢核 API。
5. 證號符合規則時，系統送出即時取回請求。
6. 系統刷新頁面資料。

**替代流程**:
- 輸入為空值時，頁面顯示「身份證字號/統一編號：不得為空值」。
- 證號不符規則時，頁面顯示原確認訊息；使用者確認後才繼續即時取回。
- API 回傳失敗時，由共用 HTTP Client 顯示錯誤狀態。

**事後條件**: 頁面顯示即時取回後的資料。

### UC-006 - 開啟通報資料明細
**使用者案例描述**: 使用者點選明細表的通報方式欄位，以頁面內嵌對話框開啟該筆完整明細。

**前置條件**: 查詢結果至少有一筆資料。

**主流程**:
1. 使用者點選一筆資料的通報方式。
2. 系統彙整該筆保單、保障、要保人及來源參數。
3. 系統開啟 AFY10100ShowDetail 頁面元件。

**替代流程**: AFY10100ShowDetail 尚未翻新時保留待轉換標記。

**事後條件**: 明細對話框開啟。

## 外部相依
### API
#### 取得頁面提示資料
**API Endpoint**: `afy10100/prompt`

**API Method**: POST

**API Request**: 無

**API Response**:
- `inputId`: string
- `isReturn`: boolean
- `isAllow`: boolean
- `role`: string
- `status`: string
- `dataMap`: object
- `resultList`: object[]
- `INSRMAP`: Record<string, string>
- `oiuIndDesc`: Record<string, string>
- `saleChnlDesc`: Record<string, string>

#### 查詢公會通報資料
**API Endpoint**: `afy10100/query`

**API Method**: POST

**API Request**:
- 查詢欄位：`inputId`、`IS_RETURN`、`role`、`status`
- 表單欄位：目前選取資料及編輯區所有具名欄位

**API Response**: 同取得頁面提示資料。

#### 修改公會通報資料
**API Endpoint**: `afy10100/edit`

**API Method**: POST

**API Request**:
- 查詢欄位：`inputId`、`IS_RETURN`、`role`、`status`
- 選取欄位：`item`
- 編輯欄位：保單識別、19 項保障金額、保經代分類、要保人資料、性別、公自費件及公會取回序號

**API Response**: 同取得頁面提示資料。

#### 刪除公會通報資料
**API Endpoint**: `afy10100/delete`

**API Method**: POST

**API Request**: 同修改公會通報資料。

**API Response**: 同取得頁面提示資料。

#### 檢核即時取回證號
**API Endpoint**: `afy10100/asynccheckid`

**API Method**: POST

**API Request**:
- `inputId`: string

**API Response**:
- `isIdError`: string - `Y` 表示不符身份證或統一證號檢核規則。

#### 即時取回公會資料
**API Endpoint**: `afy10100/async`

**API Method**: POST

**API Request**: 同修改公會通報資料。

**API Response**: 同取得頁面提示資料。
